# Snack Seven

A small, responsive single-page school snack picker. Selects seven distinct choices from the supplied 24-item menu, preserving quantities and preparation notes. Each menu entry (including “peach or plum”) counts as one choice. New rounds may include items from previous rounds.

Open `index.html` in a browser; no installation or build required. The optional Google Fonts stylesheet has local font fallbacks.

## GitHub Pages

Push these files to the `main` branch of your GitHub repository. In **Settings → Pages → Build and deployment → Source**, select **GitHub Actions**. The included workflow publishes the site on pushes to main, or through **Actions → Deploy snack picker to GitHub Pages → Run workflow** after enabling Pages.

The public URL will be shown in the workflow’s `github-pages` environment once deployment completes.
